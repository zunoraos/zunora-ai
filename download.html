How to install

🪟 Windows

  1. ZIP-Datei herunterladen und entpacken (Rechtsklick → „Alle extrahieren“).
  2. Im Ordner das Programm starten (ZunoraStore.exe bzw. Zunora Messenger.exe).
  3. Fehlt etwas, fragt Windows nach der „.NET 10 Desktop Runtime“ von Microsoft — einmal hier laden (Desktop Runtime, x64).
  4. Tipp: Installiere zuerst den Zunora App Store — darin bekommst du den Messenger mit einem Klick und immer aktuell.
  1. Download the ZIP file and extract it (right-click → “Extract All”).
  2. Start the program in the folder (ZunoraStore.exe or Zunora Messenger.exe).
  3. If something is missing, Windows asks for Microsoft's “.NET 10 Desktop Runtime” — get it here once (Desktop Runtime, x64).
  4. Tip: install the Zunora App Store first — it gets you the Messenger with one click and always up to date.

🤖 Android

  1. APK-Datei auf dem Handy herunterladen und antippen.
  2. Beim ersten Mal fragt Android, ob Apps aus dieser Quelle erlaubt sind — einschalten und zurück.
  3. Android 8 oder neuer.
  1. Download the APK file on your phone and tap it.
  2. The first time, Android asks whether apps from this source are allowed — turn it on and go back.
  3. Android 8 or newer.
